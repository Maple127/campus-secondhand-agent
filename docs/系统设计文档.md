### 1.1 登录认证流程

#### 序列图
```
┌─────────┐     ┌─────────────┐     ┌──────────────┐     ┌────────────┐     ┌──────────┐

     │                  │ 3.返回登录页面        │                  │                │
     │                  │<─────────────────────                  │                │
     │                  │                      │                  │                │
     │ 4.提交登录表单    │                      │                  │                │
     │ (username,password)│                    │                  │                │
     │─────────────────>│                      │                  │                │
     │                  │ 5.POST /admin/doLogin│                  │                │
     │                  │ (username,password)   │                  │                │
     │                  │─────────────────────>                  │                │
     │                  │                      │                  │                │
     │                  │                      │ 6.findByUsername│                │

     │                  │                      │                  │                │
     │                  │                      │ 8.返回Admin对象   │                │
     │                  │                      │<─────────────────│                │
     │                  │                      │                  │                │
     │ 9a.登录成功       │                      │                  │                │
     │   重定向到仪表盘   │                      │                  │                │
     │<─────────────────│                      │                  │                │
     │                  │                      │                  │                │

     │<─────────────────│                      │                  │                │
     │                  │                      │                  │                │
```

#### 流程说明
1. 用户访问登录页面 `/admin/login`
2. 系统返回登录表单页面
3. 用户填写用户名和密码并提交
4. 后端调用 `AdminRepository.findByUsernameAndPassword()` 验证凭证
5. 验证成功：将管理员信息存入Session，重定向到仪表盘
6. 验证失败：返回错误消息，重定向回登录页

1. 管理员点击"删除"链接
